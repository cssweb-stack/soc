Department of Sociology

A demonstration of our shared website foundation.

This demonstration shows how Sociology can use the same header, footer, typography, and layouts as GEO while supplying its own name, navigation, and contact information.

This is placeholder content for reviewing the page design. It does not describe an approved department website or announce any programs, requirements, or services.

Use the navigation above to explore the demonstration pages. Each destination has been created so that the menus and folder structure can be tested without writing the department’s final content.

The shared styles and templates are maintained in css-shared. Sociology’s page text, logo, contact details, navigation, and local settings are maintained in this SOC project.

This page is intentionally simple. Future content can use the shared headings, lists, buttons, callouts, and grids after the basic connection has been reviewed.
